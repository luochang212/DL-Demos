# 优化器：从 SGD 到 Adam

本章对应源码：
[`chapters/training_tricks/advanced_optimizer/optimizer.py`](https://github.com/luochang212/DL-Demos/blob/master/chapters/training_tricks/advanced_optimizer/optimizer.py)

## SGD

最基本的梯度下降更新为：

$$
\theta_{t+1}=\theta_t-\eta g_t
$$

它简单直接，但在峡谷形损失面中容易震荡，并且所有参数共享同一个学习率。

## Momentum

Momentum 对梯度做指数移动平均：

$$
v_t=\beta v_{t-1}+(1-\beta)g_t
$$

$$
\theta_{t+1}=\theta_t-\eta v_t
$$

它能平滑单步梯度噪声，并在方向一致的维度上积累速度。

## RMSProp

RMSProp 对梯度平方做指数移动平均：

$$
s_t=\beta s_{t-1}+(1-\beta)g_t^2
$$

$$
\theta_{t+1}=\theta_t-\eta\frac{g_t}{\sqrt{s_t}+\epsilon}
$$

梯度长期较大的参数会得到更小的有效学习率，梯度长期较小的参数会得到更大的有效学习率。

## Adam

Adam 结合 Momentum 和 RMSProp，并加入偏差校正：

$$
v_t=\beta_1v_{t-1}+(1-\beta_1)g_t
$$

$$
s_t=\beta_2s_{t-1}+(1-\beta_2)g_t^2
$$

$$
\hat v_t=\frac{v_t}{1-\beta_1^t},\qquad
\hat s_t=\frac{s_t}{1-\beta_2^t}
$$

$$
\theta_{t+1}=\theta_t-\eta\frac{\hat v_t}{\sqrt{\hat s_t}+\epsilon}
$$

核心实现：

```python title="chapters/training_tricks/advanced_optimizer/optimizer.py"
self.v_dict[k] = self.beta1 * self.v_dict[k] + (1 - self.beta1) * self.grad_dict[k]
self.s_dict[k] = self.beta2 * self.s_dict[k] + (1 - self.beta2) * (
    self.grad_dict[k] ** 2
)
v = self.v_dict[k] / (1 - self.beta1**self._num_step)
s = self.s_dict[k] / (1 - self.beta2**self._num_step)
self.param_dict[k] -= self.learning_rate * v / (np.sqrt(s) + self.eps)
```

## 学习率调度

本章还提供双曲线衰减：

$$
\eta_t=\frac{\eta_0}{1+t\cdot r}
$$

```python title="chapters/training_tricks/advanced_optimizer/optimizer.py"
def get_hyperbola_func(decay_rate: float):
    def scheduler(learning_rate_zero: float, epoch: int):
        return learning_rate_zero / (1 + epoch * decay_rate)

    return scheduler
```

## 小结

SGD 是基线；Momentum 利用一阶历史方向；RMSProp 使用二阶尺度调整步长；Adam 把二者结合起来，并通过偏差校正改善训练初期的估计。
