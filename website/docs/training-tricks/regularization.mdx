# 正则化：防止过拟合的两种武器

本章对应源码：
[`chapters/training_tricks/regularization/main.py`](https://github.com/luochang212/DL-Demos/blob/master/chapters/training_tricks/regularization/main.py)

## 过拟合

当模型容量远大于数据规模时，网络可能记住训练样本中的噪声，而不是学到可泛化的规律。训练集损失会很低，但测试集表现变差。

正则化的目标是约束模型复杂度，让决策边界更平滑。

## Weight Decay

Weight Decay 在原始损失后加入权重惩罚：

$$
L_{\mathrm{reg}}
= L_{\mathrm{original}}
+ \frac{\lambda}{2m}\sum_l \lVert W^{[l]}\rVert_F^2
$$

对应梯度为：

$$
\frac{\partial L_{\mathrm{reg}}}{\partial W^{[l]}}
= \frac{\partial L_{\mathrm{original}}}{\partial W^{[l]}}
+ \frac{\lambda}{m}W^{[l]}
$$

所以更新可以写成：

$$
W^{[l]}\leftarrow
\left(1-\frac{\eta\lambda}{m}\right)W^{[l]}
-\eta\frac{\partial L_{\mathrm{original}}}{\partial W^{[l]}}
$$

代码中只衰减权重，不衰减偏置：

```python title="chapters/training_tricks/regularization/main.py"
if self.weight_decay:
    LAMBDA = 4
    self.W[i] = (1 - learning_rate * LAMBDA / self.m) * self.W[i]
    self.W[i] -= learning_rate * self.dW_cache[i]
    self.b[i] -= learning_rate * self.db_cache[i]
```

## Dropout

Dropout 在训练时随机丢弃部分隐藏单元。代码使用 inverted dropout：训练时除以 `keep_prob`，保证激活期望不变。

$$
\tilde a_j^{[l]}=
\begin{cases}
0, & \text{drop}\\
\frac{a_j^{[l]}}{p_{\mathrm{keep}}}, & \text{keep}
\end{cases}
$$

```python title="chapters/training_tricks/regularization/main.py"
if train_mode and self.dropout and i < self.num_layer - 1:
    keep_prob = 0.5
    d = np.random.rand(*A.shape) < keep_prob
    A = A * d / keep_prob
    self.dropout_mask_cache[i] = d
```

反向传播时必须复用前向传播保存的同一个 mask。

## 小结

Weight Decay 通过限制权重规模降低模型复杂度；Dropout 通过随机子网络训练减少神经元之间的共适应。二者都服务于同一个目标：提升泛化能力。
