# 参数初始化：从零开始的训练起点

本章对应源码：
[`chapters/training_tricks/initialization/main.py`](https://github.com/luochang212/DL-Demos/blob/master/chapters/training_tricks/initialization/main.py)

## 核心问题

深层网络的第一步是设定初始权重。这个选择会直接影响信号和梯度能否稳定传播。

- 全零初始化会让同一层神经元保持完全对称，网络退化成重复的单个神经元。
- 随机初始化可以打破对称性，但方差过大会导致激活和梯度震荡。
- He 初始化根据输入维度缩放权重，适合 ReLU 网络。

## 为什么不能全零初始化

假设两层网络的权重和偏置都初始化为 0：

$$
z^{[1]} = W^{[1]}x + b^{[1]} = 0,\qquad a^{[1]} = g(0)
$$

同一层中所有神经元看到的输入、输出和梯度都相同。梯度更新后这些参数仍然相同，因此宽网络不会学到多样化特征。

## 方差传播

考虑第 $l$ 层的一个神经元：

$$
z^{[l]}=\sum_{j=1}^{n_{l-1}} W_j^{[l]}a_j^{[l-1]}
$$

若 $W_j^{[l]}$ 与 $a_j^{[l-1]}$ 独立且均值为 0，则：

$$
\operatorname{Var}(z^{[l]})
= n_{l-1}\operatorname{Var}(W^{[l]})\operatorname{Var}(a^{[l-1]})
$$

为了让每层输出方差稳定，Xavier 初始化令：

$$
\operatorname{Var}(W^{[l]})=\frac{1}{n_{l-1}}
$$

ReLU 会将大约一半的负值置零，因此 He 初始化使用更大的方差：

$$
\operatorname{Var}(W^{[l]})=\frac{2}{n_{l-1}}
$$

代码中的实现是：

```python title="chapters/training_tricks/initialization/main.py"
if initialization == 'zeros':
    self.W.append(np.zeros((neuron_cnt[i + 1], neuron_cnt[i])))
elif initialization == 'random':
    self.W.append(np.random.randn(neuron_cnt[i + 1], neuron_cnt[i]) * 5)
elif initialization == 'he':
    self.W.append(
        np.random.randn(neuron_cnt[i + 1], neuron_cnt[i])
        * np.sqrt(2 / neuron_cnt[i])
    )
```

## 小结

初始化的目标不是让参数“随机”这么简单，而是让每一层的信号规模可控。对 ReLU 网络，He 初始化通常是更稳的默认选择。
