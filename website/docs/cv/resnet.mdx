## 退化问题

直觉上，网络越深表达能力越强，至少可以通过学习恒等映射保持不变。但 ResNet 论文发现，普通深层网络在训练集上的误差也可能变高，这说明问题来自优化难度，而不是过拟合。

ResNet 的核心想法是让网络学习残差，而不是直接学习目标映射：

$$
\mathcal{H}(x)=\mathcal{F}(x)+x
$$

因此网络实际要学习的是：

$$
\mathcal{F}(x)=\mathcal{H}(x)-x
$$

如果最优映射接近恒等映射，残差函数只需要接近 0，这通常比直接拟合恒等映射更容易。

## 残差块

基本残差块可以写成：

$$
y=\mathcal{F}(x,W)+x
$$

其中 shortcut 分支把输入直接加到卷积堆的输出上。

```python title="chapters/cv/resnet/tf_main.py"
def identity_block_2(x, f, use_shortcut=True):
    x_shortcut = x
    x = layers.Conv2D(C, f, padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.Activation('relu')(x)
    x = layers.Conv2D(C, f, padding='same')(x)
    x = layers.BatchNormalization()(x)
    if use_shortcut:
        x = layers.Add()([x, x_shortcut])
    return layers.Activation('relu')(x)
```

当空间尺寸或通道数变化时，需要用 1x1 卷积投影 shortcut：

```python title="chapters/cv/resnet/tf_main.py"
x_shortcut = layers.Conv2D(filters, 1, strides=(s, s), padding='same')(x_shortcut)
x = layers.Add()([x, x_shortcut])
```

## 小结

残差连接提供了一条梯度和信息的直接通路，让深层网络更容易优化。它不是简单增加参数量，而是改变了网络要学习的函数形式。
