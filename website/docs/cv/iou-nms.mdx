IoU 瓒婃帴杩?1锛屼袱涓瓒婄浉浼硷紱瀹屽叏涓嶇浉浜ゆ椂涓?0銆備袱涓閮芥病鏈夐潰绉椂骞堕泦涔熶负闆讹紝婧愮爜灏嗙粨鏋滃畾涔変负 0锛岄伩鍏嶉櫎闆躲€?

```python title="chapters/cv/nms/iou.py"
def iou(b1, b2):
    intersection = box_intersection(b1, b2)
    inter_area = area(intersection)
    union_area = area(b1) + area(b2) - inter_area
    if union_area == 0:
        return 0.0
    return inter_area / union_area
```
