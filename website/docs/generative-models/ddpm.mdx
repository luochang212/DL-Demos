# DDPM — 去噪扩散概率模型

:::tip 本章要点
- 理解**前向过程**：如何用固定方差逐步给图像加噪
- 推导**训练目标**：如何从变分下界得到常用的噪声预测目标
- 掌握**逆向采样**：从纯噪声逐步去噪生成图像

## 1. 核心思想

扩散模型可以从两个角度理解。第一个角度来自非平衡热力学：一个复杂数据分布可以通过不断添加噪声，逐渐变成简单的标准正态分布；如果能学会这个过程的逆过程，就能从噪声生成数据。

- **前向过程**：逐步给图像添加高斯噪声，最终变成纯噪声
- **逆向过程**：学习如何从噪声中一步步恢复出图像

第二个角度是把它看成一种特殊的 VAE：

- 普通 VAE 会学习一个编码器，把图像压缩成隐变量，再学习解码器把隐变量还原成图像。
- DDPM 不学习编码器，而是把“编码”固定为逐步加噪；它也不把图像压成短向量，而是在和原图同样大小的张量上逐步变化。
- 因此，DDPM 真正要学习的是“解码器”：也就是每一步如何去掉噪声。

关键洞察：如果我们能训练一个网络精确预测每一步添加的噪声，就能从纯噪声出发逐步去噪，生成全新图像。这样做绕开了 GAN 的对抗训练，同时把生成任务转化成了更稳定的有监督回归问题：给定带噪图像 $x_t$ 和时间步 $t$，预测生成它时用到的噪声 $\varepsilon$。

## 2. 数学原理

### 2.1 前向过程

给定干净图像 $x_0$，定义 $T$ 步马尔可夫链：

$$
q(x_t \mid x_{t-1}) = \mathcal{N}(x_t;\, \sqrt{1 - \beta_t}\, x_{t-1},\, \beta_t I)
$$

其中 $\beta_t$ 是预先设定的噪声调度（线性从 $\beta_{\min}$ 到 $\beta_{\max}$）。

这个公式不是简单地把 $\beta_t$ 倍噪声加到图像上，而是从一个正态分布里采样新图像。系数 $\sqrt{1-\beta_t}$ 和方差 $\beta_t I$ 配合使用，是为了让每一步的信号缩放和噪声方差保持可控：当 $\beta_t$ 从很小的值逐步增大时，图像信息会由慢到快地衰减，最终 $x_T$ 接近标准正态噪声。

令 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{s=1}^{t}\alpha_s$，则可以**一步**从 $x_0$ 得到任意时刻的 $x_t$：

$$
q(x_t \mid x_0) = \mathcal{N}(x_t;\, \sqrt{\bar\alpha_t}\, x_0,\, (1 - \bar\alpha_t) I)
$$

即：

$$
x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I)
$$

这就是代码中 `sample_forward` 的公式。它很重要，因为训练时不需要真的从 $x_0$ 连续加噪 $t$ 次；只要随机采样一个时间步 $t$ 和一个噪声 $\varepsilon$，就能直接构造对应的 $x_t$。

### 2.2 训练目标

逆向过程定义为：

$$
p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(x_{t-1};\, \mu_\theta(x_t, t),\, \sigma_t^2 I)
$$

DDPM 证明了，当 $\beta_t$ 足够小时，最优均值可以表示为：

$$
\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar\alpha_t}}\,\varepsilon_\theta(x_t, t)\right)
$$

其中 $\varepsilon_\theta(x_t, t)$ 是网络预测的噪声。实践中常用重新加权后的简化目标：

$$
\mathcal{L} = \mathbb{E}_{x_0, \varepsilon, t}\!\left[\left\|\varepsilon - \varepsilon_\theta(x_t, t)\right\|^2\right]
$$

即：**让网络预测添加的噪声 $\varepsilon$**。训练时随机采样 $t$ 和 $\varepsilon$，构造 $x_t$，然后让网络从 $x_t$ 预测 $\varepsilon$。

为什么可以预测噪声而不是直接预测均值？因为在均值公式里，$x_t$ 和 $t$ 已知，真正未知的是构造 $x_t$ 时用到的噪声 $\varepsilon$。网络只要预测出这个噪声，就能代回公式得到逆向分布的均值。

更完整地说，DDPM 原始目标来自变分下界（VLB）：最大化训练图像通过反向过程生成出来的概率。展开后，每个时间步都会比较两个正态分布：

- 固定前向过程诱导出的真实后验 $q(x_{t-1} \mid x_t, x_0)$
- 神经网络定义的逆向分布 $p_\theta(x_{t-1} \mid x_t)$

由于方差通常固定或预设，这个 KL 项主要变成均值之间的误差；再把均值写成噪声形式，并丢掉经验上不必要的时间步权重，就得到常见的 MSE 噪声预测目标。

### 2.3 逆向采样

从 $x_T \sim \mathcal{N}(0, I)$ 出发，每一步：

$$
x_{t-1} = \mu_\theta(x_t, t) + \sigma_t\, z, \quad z \sim \mathcal{N}(0, I)
$$

代码实现了两种方差选择：
- **simple_var=True**：$\sigma_t^2 = \beta_t$（固定方差）
- **simple_var=False**：$\sigma_t^2 = \frac{1 - \bar\alpha_{t-1}}{1 - \bar\alpha_t}\,\beta_t$（后验方差）

最后一步通常不再加入随机噪声。直观上，采样已经到达 $x_0$，再加噪会破坏最终图像；公式上，当把 $\bar\alpha_0$ 约定为 $1$ 时，后验方差在最后一步为 $0$。

## 3. 模型架构

本项目提供两种去噪网络：

```
输入: 噪声图像 x_t (1, 28, 28) + 时间步 t
      │
      ▼
 ┌──────────────────────────────────────────┐
 │              ConvNet                      │
 │  Conv+BN+ReLU × N → 时间嵌入注入 → 输出   │
 │  轻量级，适合 MNIST 快速实验               │
 └──────────────────────────────────────────┘

 ┌──────────────────────────────────────────┐
 │              UNet                         │
 │  编码器: 逐步下采样 + 时间嵌入 + skip连接   │
 │  中间层: 双层残差块                        │
 │  解码器: 逐步上采样 + skip拼接 + 时间嵌入   │
 │  更强表达力，适合复杂图像                   │
 └──────────────────────────────────────────┘
      │
      ▼
输出: 预测噪声 ε (1, 28, 28)
```

**时间步嵌入**：使用正弦位置编码将整数时间步 $t$ 映射为向量，注入每一层卷积，让网络知道当前去噪到第几步。

## 4. 代码解析

### 4.1 前向扩散系数预计算

```python title="chapters/generative_models/ddpm/code/ddpm.py" showLineNumbers
class DDPM():

    def __init__(self, device, n_steps, min_beta=0.0001, max_beta=0.02):
        # highlight-start
        # 线性噪声调度：β 从 min_beta 线性增长到 max_beta
        betas = torch.linspace(min_beta, max_beta, n_steps).to(device)
        alphas = 1 - betas
        # highlight-end
        # key-start
        # 累积乘积 ᾱ_t = α_1 × α_2 × ... × α_t
        alpha_bars = torch.empty_like(alphas)
        product = 1
        for i, alpha in enumerate(alphas):
            product *= alpha
            alpha_bars[i] = product
        # key-end
        self.betas = betas
        self.alphas = alphas
        self.alpha_bars = alpha_bars
        # 预计算 clip_x0 模式的两个系数
        alpha_prev = torch.empty_like(alpha_bars)
        alpha_prev[1:] = alpha_bars[0:n_steps - 1]
        alpha_prev[0] = 1
        self.coef1 = torch.sqrt(alphas) * (1 - alpha_prev) / (1 - alpha_bars)
        self.coef2 = torch.sqrt(alpha_prev) * self.betas / (1 - alpha_bars)
```

### 4.3 逆向单步去噪

```python title="chapters/generative_models/ddpm/code/ddpm.py" showLineNumbers
    def sample_backward_step(self, x_t, t, net, simple_var=True, clip_x0=True):
        n = x_t.shape[0]
        t_tensor = torch.tensor([t] * n,
                                dtype=torch.long).to(x_t.device).unsqueeze(1)
        # 网络预测噪声 ε_θ
        eps = net(x_t, t_tensor)

        # 方差选择
        if t == 0:
            noise = 0
        else:
            if simple_var:
                var = self.betas[t]
            else:
                var = (1 - self.alpha_bars[t - 1]) / (
                    1 - self.alpha_bars[t]) * self.betas[t]
            noise = torch.randn_like(x_t) * torch.sqrt(var)

        # key-start
        # clip_x0 模式：先估计 x_0，裁剪到 [-1,1]，再计算均值
        # 这种方式比直接用 ε 估计均值更稳定
        if clip_x0:
            x_0 = (x_t - torch.sqrt(1 - self.alpha_bars[t]) *
                   eps) / torch.sqrt(self.alpha_bars[t])
            x_0 = torch.clip(x_0, -1, 1)
            mean = self.coef1[t] * x_t + self.coef2[t] * x_0
        # key-end
        else:
            mean = (x_t -
                    (1 - self.alphas[t]) / torch.sqrt(1 - self.alpha_bars[t]) *
                    eps) / torch.sqrt(self.alphas[t])
        x_t = mean + noise
        return x_t
```

### 4.4 UNet 时间步嵌入

```python title="chapters/generative_models/ddpm/code/network.py" showLineNumbers
class PositionalEncoding(nn.Module):

    def __init__(self, max_seq_len, d_model):
        super().__init__()
        assert d_model % 2 == 0
        pe = torch.zeros(max_seq_len, d_model)
        i_seq = torch.linspace(0, max_seq_len - 1, max_seq_len)
        j_seq = torch.linspace(0, d_model - 2, d_model // 2)
        pos, two_i = torch.meshgrid(i_seq, j_seq)
        # key-start
        # 正弦位置编码：让网络区分不同时间步
        pe_2i   = torch.sin(pos / 10000**(two_i / d_model))
        pe_2i_1 = torch.cos(pos / 10000**(two_i / d_model))
        pe = torch.stack((pe_2i, pe_2i_1), 2).reshape(max_seq_len, d_model)
        # key-end
        self.embedding = nn.Embedding(max_seq_len, d_model)
        self.embedding.weight.data = pe
        self.embedding.requires_grad_(False)
```

## 5. 训练细节

<Tabs>
  <TabItem value="loss" label="训练循环" default>

核心训练逻辑：随机采样时间步 $t$，前向加噪，然后让网络预测噪声。虽然 DDPM 有 $T$ 个去噪步骤，但每次训练只抽一个时间步；长期训练后，网络会在所有噪声强度上都学会预测噪声。

```python title="训练伪代码"
for x_0 in dataloader:
    t = torch.randint(0, n_steps, (batch_size,))
    eps = torch.randn_like(x_0)
    x_t = ddpm.sample_forward(x_0, t, eps)
    eps_pred = net(x_t, t)
    loss = F.mse_loss(eps_pred, eps)
    loss.backward()
    optimizer.step()
```

  </TabItem>
  <TabItem value="sampling" label="采样循环">

采样阶段从随机噪声开始，按时间步倒序调用同一个去噪网络。每一步先预测噪声，再用预测噪声计算均值，并根据方差设置决定是否加入随机扰动。

```python title="采样伪代码"
x_t = torch.randn(batch_size, channels, height, width)
for t in reversed(range(n_steps)):
    eps_pred = net(x_t, t)
    mean = compute_reverse_mean(x_t, t, eps_pred)
    if t > 0:
        noise = torch.randn_like(x_t)
        x_t = mean + sigma_t * noise
    else:
        x_t = mean
return x_t
```

采样速度慢是 DDPM 的主要代价：标准设置会执行约 1000 次网络推理。下一章 DDIM 会保留同一个训练好的噪声预测网络，但改用跳步采样来减少推理次数。

### 6.1 数据准备

DDPM 训练使用 MNIST 手写数字图片。

- 数据来源：`torchvision.datasets.MNIST`
- 官方来源：[The MNIST Database](http://yann.lecun.com/exdb/mnist/)
- 默认路径：`data/mnist/`
- 数据规模：60,000 张训练图片，10,000 张测试图片，灰度 28×28
- 用途：快速训练和观察扩散模型从噪声生成数字的效果

数据加载代码会执行：

```python title="chapters/generative_models/ddpm/code/dataset.py"
ToTensor()
Lambda(lambda x: (x - 0.5) * 2)
```

也就是把像素从 `[0, 1]` 归一化到 `[-1, 1]`，与采样输出范围保持一致。
