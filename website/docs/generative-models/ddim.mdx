# DDIM — 去噪扩散隐式模型

:::tip 本章要点
- DDIM 是 DDPM 的采样器改造：训练目标不变，采样过程改变。
- DDIM 使用时间步子序列，从 $x_{\tau_i}$ 直接跳到 $x_{\tau_{i-1}}$。
- $\eta=0$ 时采样是确定性的；$\eta>0$ 时重新引入随机噪声。
- 源码入口在 [`chapters/generative_models/ddim/code/main.py`](https://github.com/luochang212/DL-Demos/blob/master/chapters/generative_models/ddim/code/main.py)。
:::

:::info 前置章节
DDIM 复用了 DDPM 的前向扩散和噪声预测训练目标。建议先读 [DDPM](./ddpm)。
:::

---

## 1. DDPM 的采样瓶颈

DDPM 的标准逆向过程逐步采样：

$$
x_T \rightarrow x_{T-1} \rightarrow \cdots \rightarrow x_0
$$

如果 $T=1000$，生成一张图就要调用 1000 次噪声预测网络。DDIM 的问题是：

> 能不能不改训练目标，只在采样时跳过一部分时间步？

答案是可以。DDIM 构造一个更短的时间步子序列：

$$
\tau_1 < \tau_2 < \cdots < \tau_S,\quad S \ll T
$$

反向采样时直接从 $x_{\tau_i}$ 跳到 $x_{\tau_{i-1}}$。

---

## 2. 训练目标不变

DDIM 仍然使用 DDPM 的前向闭式：

$$
x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon
$$

训练网络预测噪声：

$$
L_{\text{simple}}
=
\mathbb{E}_{x_0,t,\epsilon}
\left[
\left\|
\epsilon-\epsilon_\theta(x_t,t)
\right\|_2^2
\right]
$$

所以 DDPM 训练好的噪声预测网络可以直接用于 DDIM 采样。

---

## 3. DDIM 更新公式

从 $x_t$ 跳到更早的 $x_s$，其中 $s<t$。先用网络预测噪声恢复 $\hat{x}_0$：

$$
\hat{x}_0
=
\frac{x_t-\sqrt{1-\bar\alpha_t}\epsilon_\theta(x_t,t)}
{\sqrt{\bar\alpha_t}}
$$

DDIM 采样公式写作：

$$
x_s
=
\sqrt{\bar\alpha_s}\hat{x}_0
+
\sqrt{1-\bar\alpha_s-\sigma_t^2}\epsilon_\theta(x_t,t)
+
\sigma_t z
$$

其中：

$$
\sigma_t
=
\eta
\sqrt{
\frac{1-\bar\alpha_s}{1-\bar\alpha_t}
\left(
1-\frac{\bar\alpha_t}{\bar\alpha_s}
\right)
}
$$

把 $\hat{x}_0$ 展开后，就是代码里的三项：

```python title="chapters/generative_models/ddim/code/ddim.py"
first_term = (ab_prev / ab_cur) ** 0.5 * x
second_term = (
    (1 - ab_prev - var) ** 0.5
    - (ab_prev * (1 - ab_cur) / ab_cur) ** 0.5
) * eps
third_term = var**0.5 * noise
x = first_term + second_term + third_term
```

---

## 4. eta 控制随机性

当 $\eta=0$：

$$
\sigma_t = 0
$$

采样过程不再加入额外噪声。给定同一个初始 $x_T$，输出固定，因此这是确定性采样。

当 $\eta=1$ 且使用完整相邻时间步时，方差形式对应 DDPM 的逐步采样。若使用跳步子序列，$\eta=1$ 仍然不是原始 1000 步 DDPM 的完整马尔可夫链。

:::warning 项目中的 `simple_var`
源码保留了一个教学用的 `simple_var=True` 简化分支。要观察标准 DDIM 的 $\eta$ 控制，请使用 `simple_var=False`，命令行采样默认走这个分支。
:::

## 5. 运行代码

不下载数据的 smoke：

```powershell
uv run python -m chapters.generative_models.ddim.code.main --help
uv run python -m chapters.generative_models.ddim.code.main --mode smoke --device cpu
```

MNIST 训练：

```powershell
uv run python -m chapters.generative_models.ddim.code.main --mode train --device auto --data-root data/mnist --epochs 1 --batch-size 128
```

DDIM 采样：

```powershell
uv run python -m chapters.generative_models.ddim.code.main --mode sample --device auto --checkpoint work_dirs/ddim/mnist.pth --output work_dirs/ddim/sample.jpg --ddim-step 20 --eta 0
```

输出默认写入 `work_dirs/ddim/`。

---

## 6. 数据与权重

- MNIST 数据来自 `torchvision.datasets.MNIST`，默认放在 `data/mnist/`。
- 本仓库不提交 `data/`、checkpoint 或生成的大批量图片。
- 默认 checkpoint 是 `work_dirs/ddim/mnist.pth`。
- 本章暂不内置 Hugging Face 预训练权重。若后续引入，应在章节中记录来源、许可证、文件大小、保存路径和加载命令。
