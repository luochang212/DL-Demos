# VAE — 变分自编码器

:::tip 本章要点
- 从普通自编码器（AE）出发，理解为什么“会重建”不等于“会生成”
- 理解 VAE 的核心改造：编码器输出的是一个分布，而不是一个固定向量
- 推导 VAE 的训练目标：重建误差 + KL 正则项
- 掌握重参数化技巧：让随机采样也能参与反向传播
- 跑通 [`chapters/generative_models/vae/`](https://github.com/luochang212/DL-Demos/tree/master/chapters/generative_models/vae) 的训练、重建和生成流程
:::

## 1. 从 AE 到 VAE

图像生成模型不能只有一个固定输出。它需要一个输入，用来决定“这次要生成哪一张图”。通常我们把这个输入记作隐变量 $z$，并希望相近的 $z$ 生成相近的图像。

普通自编码器（Autoencoder, AE）正是从这个想法出发：

```text
图像 x -> 编码器 Encoder -> 压缩向量 z -> 解码器 Decoder -> 重建图像 x_hat
```

训练时，AE 只需要让重建图像 $x_{hat}$ 尽量接近原图 $x$。问题是：这只能保证模型会重建训练样本，不能保证随机采样一个 $z$ 后也能生成合理图像。

### AE 的问题：隐空间没有结构

如果编码器足够强，AE 可以把每张训练图像记成一个很孤立的点。这样做重建没问题，但隐空间中大部分区域没有被训练过。生成时如果从标准正态分布随机采样一个 $z$，它很可能落在这些“空白区域”，解码结果就会不可控。

VAE 的关键改造是：

```text
不要把一张图编码成一个点，而是编码成一个正态分布。
```

编码器不再直接输出 $z$，而是输出均值 $\mu$ 和对数方差 $\log\sigma^2$：

$$
q_\phi(z \mid x) = \mathcal{N}(\mu_\phi(x), \sigma_\phi^2(x) I)
$$

训练时从这个分布里采样 $z$ 再解码；同时让这个分布靠近标准正态分布 $\mathcal{N}(0, I)$。这样，生成时直接从 $\mathcal{N}(0, I)$ 采样，解码器也更可能见过类似区域。

## 2. VAE 到底优化什么

VAE 的损失由两部分组成：

| 项 | 作用 | 代码里的实现 |
| --- | --- | --- |
| 重建误差 | 让解码图像接近输入图像 | `F.mse_loss(y_hat, y)` |
| KL 散度 | 让编码分布接近标准正态分布 | `-0.5 * sum(1 + logvar - mean**2 - exp(logvar))` |

直觉上，重建误差负责“画得像”，KL 散度负责“隐空间规整”。如果只有重建误差，模型会退化成普通 AE；如果 KL 权重过大，编码器可能被迫输出过于接近标准正态的分布，导致重建质量下降。

本项目使用的是一个加权目标：

$$
\mathcal{L}
= \underbrace{\|x - \hat{x}\|_2^2}_{\text{重建误差}}
+ \lambda \underbrace{D_{\mathrm{KL}}(q_\phi(z \mid x) \| p(z))}_{\text{KL 正则}}
$$

其中 `kl_weight = 0.00025`，也就是 $\lambda = 0.00025$。

### 2.1 从 ELBO 看 VAE

从概率模型角度看，生成过程是：

$$
z \sim p(z) = \mathcal{N}(0, I)
$$

$$
x \sim p_\theta(x \mid z)
$$

我们希望最大化数据的对数似然：

$$
\log p_\theta(x) = \log \int p_\theta(x \mid z)p(z)\,dz
$$

这个积分通常无法直接算，所以引入编码器分布 $q_\phi(z \mid x)$ 近似真实后验。经过变分推导，可以得到证据下界（ELBO）：

$$
\log p_\theta(x) \ge
\mathbb{E}_{q_\phi(z \mid x)}[\log p_\theta(x \mid z)]
- D_{\mathrm{KL}}(q_\phi(z \mid x) \| p(z))
$$

最大化 ELBO，等价于同时做两件事：

1. 提高重建概率：给定 $z$ 后，解码器应该能还原 $x$。
2. 降低 KL 散度：编码器输出的分布应尽量接近先验 $p(z)$。

### 2.2 KL 散度的直觉

KL 散度可以理解成“用一个分布去近似另一个分布时，多付出的编码成本”。在 VAE 里，我们用编码器给出的 $q_\phi(z \mid x)$ 去靠近标准正态先验 $p(z)$。当两个分布一致时，KL 散度为 0；差异越大，KL 项越大。

对于对角高斯分布：

$$
q_\phi(z \mid x)=\mathcal{N}(\mu,\sigma^2 I), \quad p(z)=\mathcal{N}(0,I)
$$

KL 项有解析形式：

$$
D_{\mathrm{KL}}(q_\phi(z \mid x) \| p(z))
= -\frac{1}{2}\sum_{j=1}^{d}
\left(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\right)
$$

这正对应项目里的代码：

```python title="chapters/generative_models/vae/code/main.py"
kl_loss = torch.mean(
    -0.5 * torch.sum(1 + logvar - mean**2 - torch.exp(logvar), 1), 0
)
```

## 3. 重参数化技巧

问题来了：从正态分布中采样是随机操作，梯度不能直接穿过“采样”本身传回编码器。

VAE 的做法是把随机性挪到一个独立噪声 $\varepsilon$ 上：

$$
z = \mu + \sigma \odot \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I)
$$

这样，$\varepsilon$ 与模型参数无关，梯度可以通过 $\mu$ 和 $\sigma$ 正常反传。

:::info 为什么输出 `logvar`
模型输出的是 `logvar`，也就是 $\log\sigma^2$，而不是直接输出 $\sigma^2$。这样可以避免方差为负数，也避免在损失函数里对接近 0 的方差再取对数导致数值不稳定。
:::

## 4. 模型结构

本项目的 VAE 针对 **64×64 CelebA 人脸图像**设计。

```text
输入图像 (3, 64, 64)
  -> Conv2d stride=2, channels 16   -> (16, 32, 32)
  -> Conv2d stride=2, channels 32   -> (32, 16, 16)
  -> Conv2d stride=2, channels 64   -> (64, 8, 8)
  -> Conv2d stride=2, channels 128  -> (128, 4, 4)
  -> Conv2d stride=2, channels 256  -> (256, 2, 2)
  -> flatten
  -> Linear -> mean    (128维)
  -> Linear -> logvar  (128维)
  -> 重参数化采样 z
  -> Linear + reshape -> (256, 2, 2)
  -> ConvTranspose2d 逐步上采样
  -> 输出图像 (3, 64, 64)
```

编码器用卷积逐步压缩空间尺寸、增加通道数；解码器做相反操作，用反卷积把隐变量还原成图像。

<Tabs>
  <TabItem value="encoder" label="编码器" default>

```python title="chapters/generative_models/vae/code/model.py"
prev_channels = 3
modules = []
img_length = 64
for cur_channels in hiddens:
    modules.append(
        nn.Sequential(
            nn.Conv2d(prev_channels, cur_channels, kernel_size=3, stride=2, padding=1),
            nn.BatchNorm2d(cur_channels),
            nn.ReLU(),
        )
    )
    prev_channels = cur_channels
    img_length //= 2
self.encoder = nn.Sequential(*modules)
self.mean_linear = nn.Linear(prev_channels * img_length * img_length, latent_dim)
self.var_linear = nn.Linear(prev_channels * img_length * img_length, latent_dim)
```

  </TabItem>
  <TabItem value="decoder" label="解码器">

```python title="chapters/generative_models/vae/code/model.py"
self.decoder_projection = nn.Linear(
    latent_dim, prev_channels * img_length * img_length
)
self.decoder_input_chw = (prev_channels, img_length, img_length)

for i in range(len(hiddens) - 1, 0, -1):
    modules.append(
        nn.Sequential(
            nn.ConvTranspose2d(
                hiddens[i],
                hiddens[i - 1],
                kernel_size=3,
                stride=2,
                padding=1,
                output_padding=1,
            ),
            nn.BatchNorm2d(hiddens[i - 1]),
            nn.ReLU(),
        )
    )
```

  </TabItem>
  <TabItem value="sample" label="生成采样">

```python title="chapters/generative_models/vae/code/model.py"
def sample(self, device=None):
    if device is None:
        device = next(self.parameters()).device
    z = torch.randn(1, self.latent_dim, device=device)
    x = self.decoder_projection(z)
    x = torch.reshape(x, (-1, *self.decoder_input_chw))
    decoded = self.decoder(x)
    return decoded
```

生成时不需要编码器，直接从标准正态分布采样 $z$，再交给解码器。

## 5. 训练与运行

### 5.1 数据准备

VAE 正式训练使用 CelebA 的对齐人脸图片；如果只想快速看到模型学习效果，可以先用 MNIST。

#### MNIST 快速效果

- 数据来源：`torchvision.datasets.MNIST`
- 默认路径：`data/mnist/`
- 用途：快速训练和观察数字重建/生成效果，不代表最终人脸生成质量
- 处理方式：`Resize((64, 64))`、转成 3 通道、`ToTensor()`，以复用同一个 VAE 网络结构

```powershell
uv run python -m chapters.generative_models.vae.code.main --mode train --dataset mnist --epochs 1 --device auto --checkpoint work_dirs/vae/mnist_model.pth
uv run python -m chapters.generative_models.vae.code.main --mode generate --device auto --checkpoint work_dirs/vae/mnist_model.pth --output work_dirs/vae/mnist_sample.jpg
```

#### CelebA 正式数据

VAE 正式训练使用 CelebA 的对齐人脸图片。本章代码只读取图片，不使用属性标注。

- 官方来源：[CelebA Dataset - MMLab](https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html)
- 可用镜像：[Kaggle CelebA Dataset](https://www.kaggle.com/datasets/jessicali9530/celeba-dataset)
- 数据规模：官方说明包含 202,599 张人脸图片和 40 个属性标注
- 使用限制：CelebA 主要用于非商业研究；下载和使用时应遵守原始数据集许可

默认数据目录是：


目录内应直接放置 CelebA 的对齐裁剪图片，例如：

## 6. 代码实战：一次训练迭代

下面这段就是 VAE 训练的核心闭环：

```python title="chapters/generative_models/vae/code/main.py"
for x in dataloader:
    x = x.to(device)
    y_hat, mean, logvar = model(x)
    loss = loss_fn(x, y_hat, mean, logvar)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

每一步发生的事情是：

1. `model(x)`：编码器输出 `mean` 和 `logvar`，采样得到 `z`，解码器输出 `y_hat`。
2. `loss_fn(...)`：计算重建误差和 KL 正则。
3. `loss.backward()`：通过重参数化路径把梯度传回编码器和解码器。
4. `optimizer.step()`：更新模型参数。

损失函数对应的代码：

```python title="chapters/generative_models/vae/code/main.py"
def loss_fn(y, y_hat, mean, logvar):
    recons_loss = F.mse_loss(y_hat, y)
    kl_loss = torch.mean(
        -0.5 * torch.sum(1 + logvar - mean**2 - torch.exp(logvar), 1), 0
    )
    loss = recons_loss + kl_loss * kl_weight
    return loss
```

:::warning 实验提示
VAE 生成效果通常不如现代扩散模型锐利。它的价值不只在“生成图片质量”，更在于理解隐变量建模、变分推断、KL 正则和重参数化。这些概念会在后续 DDPM、DDIM、VQVAE 和潜扩散模型里反复出现。
:::

## 7. 与后续章节的关系

VAE 是后续生成模型章节的地基：

- **DDPM / DDIM**：可以看成更具体的变分生成模型。编码过程不再由神经网络学习，而是固定为逐步加噪；解码器则学习逐步去噪。
- **VQVAE**：把连续隐空间换成离散 codebook，让图像生成变成更小、更结构化的离散 token 生成问题。
- **潜扩散模型**：先用 VAE 或类似自编码器把图像压缩到潜空间，再在潜空间里训练扩散模型，从而降低计算成本。
