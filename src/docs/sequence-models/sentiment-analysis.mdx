## 1. 任务定义

**情感分析**（Sentiment Analysis）：给定一段影评文本，判断其情感极性（正面/负面）。

数据集：[IMDB Movie Review](https://ai.stanford.edu/~amaas/data/sentiment/)，包含 50,000 条影评，正面和负面各占一半。

这是一个典型的**序列分类**任务：
- 输入：变长文本序列
- 输出：二分类标签（positive / negative）

---

## 2. 数学原理

### 2.1 词嵌入

文本不能直接输入神经网络，需要先把每个词编码成数值向量。最简单的方式是 one-hot，但 one-hot 有两个问题：
1. **维度极高**（词汇表可能有几万个词）
2. **无法表达词义关系**（「猫」和「狗」的向量距离和「猫」和「汽车」一样远）

**GloVe**（Global Vectors for Word Representation）通过在大规模语料上统计词共现矩阵，将每个词映射到一个低维稠密向量（如 100 维），使得语义相近的词在向量空间中距离相近。

### 2.2 词向量类比

GloVe 词向量有一个著名的性质——**类比推理**：

$$
\vec{king} - \vec{man} + \vec{woman} \approx \vec{queen}
$$

本项目 [`dldemos/SentimentAnalysis/glove.py`](https://github.com/luochang212/DL-Demos/blob/master/dldemos/SentimentAnalysis/glove.py) 中实现了类比推理的验证：

```python title="dldemos/SentimentAnalysis/glove.py"
def get_counterpart(x1, y1, x2):
    """Find y2 that makes x1-y1 = x2-y2."""
    target = x2_vec - x1_vec + y1_vec
    # 在词汇表中按余弦相似度寻找最接近 target 的词向量
    # ...

print(get_counterpart('man', 'woman', 'king'))    # → queen
print(get_counterpart('more', 'less', 'long'))    # → shorter
print(get_counterpart('apple', 'red', 'banana'))  # → yellow
```

### 2.3 序列分类的 RNN 架构

```
"This movie is great"
     ↓   ↓    ↓    ↓
   [G] [G]  [G]  [G]    ← GloVe 词向量 (100维)
     ↓   ↓    ↓    ↓
   [GRU]→[GRU]→[GRU]→[GRU]  ← GRU 逐词编码
                       ↓
                    取最后隐藏状态
                       ↓
                  Linear → Sigmoid
                       ↓
                   正面 / 负面
```

RNN 从左到右处理每个词，最后取**每条序列真实末尾的隐藏状态**作为整个句子的表示，送入分类器；批处理中的 padding 不应参与编码。

## 3. 代码解析

### 3.1 数据加载与预处理

```python title="dldemos/SentimentAnalysis/main.py" showLineNumbers
GLOVE_DIM = 100
GLOVE = GloVe(name='6B', dim=GLOVE_DIM)

class IMDBDataset(Dataset):
    def __init__(self, is_train=True, dir='data/aclImdb'):
        self.tokenizer = get_tokenizer('basic_english')
        pos_lines = read_imdb(dir, 'pos', is_train)
        neg_lines = read_imdb(dir, 'neg', is_train)
        self.lines = pos_lines + neg_lines
        self.pos_length = len(pos_lines)

    def __getitem__(self, index):
        sentence = self.tokenizer(self.lines[index])
        # key-start
        x = GLOVE.get_vecs_by_tokens(sentence)  # 每个词 → 100维 GloVe 向量
        label = 1 if index < self.pos_length else 0
        # key-end
        return x, label
```

### 3.2 变长序列的批处理

不同影评长度不同，无法直接组成 batch。用 `pad_sequence` 填充到同一长度：

```python title="dldemos/SentimentAnalysis/main.py" showLineNumbers
def get_dataloader(dir='data/aclImdb'):
    # key-start
    def collate_fn(batch):
        x, y = zip(*batch)
        lengths = torch.tensor([len(sentence) for sentence in x])
        x_pad = pad_sequence(x, batch_first=True)  # 填充到 batch 内最大长度
        y = torch.Tensor(y)
        return x_pad, lengths, y
    # key-end
    train_dataloader = DataLoader(IMDBDataset(True, dir),
                                  batch_size=32, shuffle=True,
                                  collate_fn=collate_fn)
    return train_dataloader, ...
```

### 3.3 分类模型

```python title="dldemos/SentimentAnalysis/main.py" showLineNumbers
class RNN(torch.nn.Module):
    def __init__(self, hidden_units=64, dropout_rate=0.5):
        super().__init__()
        self.drop = nn.Dropout(dropout_rate)
        # key-start
        self.rnn = nn.GRU(GLOVE_DIM, hidden_units, 1, batch_first=True)
        self.linear = nn.Linear(hidden_units, 1)
        self.sigmoid = nn.Sigmoid()
        # key-end

    def forward(self, x, lengths):
        emb = self.drop(x)                # Dropout 正则化
        # key-start
        # 打包变长序列，让 GRU 跳过 padding
        packed = pack_padded_sequence(emb, lengths.cpu(),
                                      batch_first=True,
                                      enforce_sorted=False)
        _, hidden = self.rnn(packed)
        output = self.linear(hidden[-1])  # 每条影评真实末尾的隐藏状态
        output = self.sigmoid(output)     # 二分类概率
        # key-end
        return output
```

### 3.4 训练与评估

```python title="dldemos/SentimentAnalysis/main.py" showLineNumbers
# 训练
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
citerion = nn.BCELoss()
for epoch in range(100):
    for x, lengths, y in train_dataloader:
        hat_y = model(x, lengths)
        loss = citerion(hat_y.squeeze(-1), y)
        optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 0.5)  # 梯度裁剪
        optimizer.step()

# 评估
model.eval()
for x, lengths, y in test_dataloader:
    with torch.no_grad():
        hat_y = model(x, lengths).squeeze(-1)
    predictions = torch.where(hat_y > 0.5, 1, 0)
    accuracy = torch.mean((predictions == y).float())
```

## 4. 模型架构总结

```
输入: 变长英文文本
  ↓ basic_english tokenizer 分词
  ↓ GloVe(6B, 100d) 词嵌入
  ↓ Dropout(0.5)
  ↓ pack_padded_sequence 跳过 padding
  ↓ GRU(input=100, hidden=64, layers=1)
  ↓ 取每条影评真实末尾的隐藏状态 (64维)
  ↓ Linear(64 → 1)
  ↓ Sigmoid
输出: 情感概率 [0, 1]
```
