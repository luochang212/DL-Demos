## 1. 为什么需要 RNN

全连接网络和 CNN 假设输入之间相互独立。但很多数据天然是**序列**：

- 文本：「我今天」→ 下一个字是「去」比「了」更合理
- 时间序列：股票价格、天气变化
- 语音：前后帧强相关

RNN 通过**隐藏状态**（hidden state）在时间步之间传递信息，让网络具有「记忆」。

---

## 2. 数学原理

### 2.1 基本结构

RNN 在每个时间步 $t$ 的计算：

$$
a^{(t)} = g(W_a [a^{(t-1)}, x^{(t)}] + b_a)
$$

$$
\hat{y}^{(t)} = \sigma(W_y a^{(t)} + b_y)
$$

其中 $a^{(t)}$ 是隐藏状态，$[\cdot, \cdot]$ 表示拼接，$g$ 通常是 $\tanh$。

```
时间步展开：

x(1) ──→ [RNN] ──→ x(2) ──→ [RNN] ──→ x(3) ──→ ...
            │                   │                   │
            a(1) ──────────→   a(2) ──────────→   a(3)
            │                   │                   │
           ŷ(1)               ŷ(2)               ŷ(3)
```

每个时间步共享同一组权重 $W_a, W_y$。

### 2.2 字符级语言模型

将单词的每个字符用 one-hot 编码输入 RNN：

- **输入**：当前字符的 embedding（或 one-hot）
- **目标**：预测下一个字符的概率分布
- **训练**：最小化交叉熵 $\sum_t -\log P(c^{(t+1)} \mid c^{(1)}, ..., c^{(t)})$

训练完成后，RNN 可以通过采样生成新的「单词」——采样出概率最高的下一个字符，循环往复。

### 2.3 梯度裁剪

RNN 的梯度通过时间步反向传播（BPTT），经过多个时间步后容易梯度爆炸。常用的解决方案是**梯度裁剪**：

$$
\text{if } \|\nabla\| > \theta: \quad \nabla \leftarrow \frac{\theta}{\|\nabla\|} \nabla
$$

### 3.1 RNN1：手动循环实现

```python title="dldemos/BasicRNN/models.py" showLineNumbers
class RNN1(nn.Module):

    def __init__(self, hidden_units=32):
        super().__init__()
        self.hidden_units = hidden_units
        # key-start
        # 一个 Linear 同时处理 [a(t-1), x(t)] 的拼接
        self.linear_a = nn.Linear(hidden_units + EMBEDDING_LENGTH, hidden_units)
        self.linear_y = nn.Linear(hidden_units, EMBEDDING_LENGTH)
        self.tanh = nn.Tanh()
        # key-end

    def forward(self, word):
        batch, Tx = word.shape[0:2]
        word = torch.transpose(word, 0, 1)  # (Tx, batch, embedding)
        output = torch.empty_like(word)

        a = torch.zeros(batch, self.hidden_units, device=word.device)
        x = torch.zeros(batch, EMBEDDING_LENGTH, device=word.device)
        # key-start
        for i in range(Tx):
            # 核心循环：a(t) = tanh(W · [a(t-1), x(t)] + b)
            next_a = self.tanh(self.linear_a(torch.cat((a, x), 1)))
            hat_y = self.linear_y(next_a)   # 预测下一个字符
            output[i] = hat_y
            x = word[i]                     # 下一个时间步的输入
            a = next_a                       # 传递隐藏状态
        # key-end
        return torch.transpose(output, 0, 1)
```

### 3.2 语言模型：计算序列概率

```python title="dldemos/BasicRNN/models.py" showLineNumbers
    @torch.no_grad()
    def language_model(self, word):
        batch, Tx = word.shape[0:2]
        word = torch.transpose(word, 0, 1)
        word_label = torch.argmax(word, 2)  # one-hot → index

        # key-start
        # P(word) = ∏ P(c(t+1) | c(1), ..., c(t))
        output = torch.ones(batch, device=word.device)
        a = torch.zeros(batch, self.hidden_units, device=word.device)
        x = torch.zeros(batch, EMBEDDING_LENGTH, device=word.device)
        for i in range(Tx):
            next_a = self.tanh(self.linear_a(torch.cat((a, x), 1)))
            hat_y = F.softmax(self.linear_y(next_a), 1)
            probs = hat_y[torch.arange(batch), word_label[i]]  # 取目标字符的概率
            output *= probs                                      # 累乘
            x = word[i]
            a = next_a
        # key-end
        return output
```

### 3.3 采样：生成新单词

```python title="dldemos/BasicRNN/models.py" showLineNumbers
    @torch.no_grad()
    def sample_word(self, device='cuda:0'):
        output = ''
        a = torch.zeros(1, self.hidden_units, device=device)
        x = torch.zeros(1, EMBEDDING_LENGTH, device=device)
        # key-start
        for i in range(10):
            next_a = self.tanh(self.linear_a(torch.cat((a, x), 1)))
            hat_y = F.softmax(self.linear_y(next_a), 1)
            # 按概率分布随机采样一个字符
            np_prob = hat_y[0].detach().cpu().numpy()
            letter = np.random.choice(LETTER_LIST, p=np_prob)
            output += letter
            if letter == ' ':  # 空格 = EOS
                break
            # 采样的字符作为下一个时间步的输入
            x = torch.zeros(1, EMBEDDING_LENGTH, device=device)
            x[0][LETTER_MAP[letter]] = 1
            a = next_a
        # key-end
        return output
```

### 3.4 RNN2：GRU + Embedding 实现

```python title="dldemos/BasicRNN/models.py" showLineNumbers
class RNN2(nn.Module):

    def __init__(self, hidden_units=64, embeding_dim=64, dropout_rate=0.2):
        super().__init__()
        self.drop = nn.Dropout(dropout_rate)
        # key-start
        self.encoder = nn.Embedding(EMBEDDING_LENGTH, embeding_dim)
        self.rnn = nn.GRU(embeding_dim, hidden_units, 1, batch_first=True)
        self.decoder = nn.Linear(hidden_units, EMBEDDING_LENGTH)
        # key-end

    def forward(self, word):
        batch, Tx = word.shape[0:2]
        first_letter = word.new_zeros(batch, 1)
        x = torch.cat((first_letter, word[:, 0:-1]), 1)  # 延迟一步：用前一个字符预测当前
        hidden = torch.zeros(1, batch, self.hidden_units, device=word.device)
        emb = self.drop(self.encoder(x))
        output, hidden = self.rnn(emb, hidden)
        y = self.decoder(output.reshape(batch * Tx, -1))
        return y.reshape(batch, Tx, -1)
```

**GRU**（Gated Recurrent Unit）是 RNN 的改进版本，通过**更新门**和**重置门**控制信息流动，缓解梯度消失问题。

## 4. RNN1 vs RNN2 对比

| 特性 | RNN1 | RNN2 |
|------|------|------|
| 循环单元 | 手动实现（$\tanh$ + Linear） | `nn.GRU` |
| 输入编码 | One-hot | `nn.Embedding` |
| 隐藏单元数 | 32 | 64 |
| Dropout | ❌ | ✅ |
| 训练速度 | 较慢（手动循环） | 较快（GRU 优化） |
