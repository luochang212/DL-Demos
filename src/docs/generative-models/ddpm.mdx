# DDPM — 去噪扩散概率模型

:::tip 本章要点

## 1. 核心思想

扩散模型的设计灵感来自非平衡热力学：

- **前向过程**：逐步给图像添加高斯噪声，最终变成纯噪声
- **逆向过程**：学习如何从噪声中一步步恢复出图像

关键洞察：如果我们能训练一个网络精确预测每一步添加的噪声，就能从纯噪声出发逐步去噪，生成全新图像。

---

## 2. 数学原理

### 2.1 前向过程

给定干净图像 $x_0$，定义 $T$ 步马尔可夫链：

$$
q(x_t \mid x_{t-1}) = \mathcal{N}(x_t;\, \sqrt{1 - \beta_t}\, x_{t-1},\, \beta_t I)
$$

其中 $\beta_t$ 是预先设定的噪声调度（线性从 $\beta_{\min}$ 到 $\beta_{\max}$）。

令 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{s=1}^{t}\alpha_s$，则可以**一步**从 $x_0$ 得到任意时刻的 $x_t$：

$$
q(x_t \mid x_0) = \mathcal{N}(x_t;\, \sqrt{\bar\alpha_t}\, x_0,\, (1 - \bar\alpha_t) I)
$$

即：

$$
x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I)
$$

这就是代码中 `sample_forward` 的公式。

### 2.2 训练目标

逆向过程定义为：

$$
p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(x_{t-1};\, \mu_\theta(x_t, t),\, \sigma_t^2 I)
$$

DDPM 证明了，当 $\beta_t$ 足够小时，最优均值可以表示为：

$$
\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar\alpha_t}}\,\varepsilon_\theta(x_t, t)\right)
$$

其中 $\varepsilon_\theta(x_t, t)$ 是网络预测的噪声。最终训练目标简化为：

$$
\mathcal{L} = \mathbb{E}_{x_0, \varepsilon, t}\!\left[\left\|\varepsilon - \varepsilon_\theta(x_t, t)\right\|^2\right]
$$

即：**让网络预测添加的噪声 $\varepsilon$**。训练时随机采样 $t$ 和 $\varepsilon$，构造 $x_t$，然后让网络从 $x_t$ 预测 $\varepsilon$。

### 2.3 逆向采样

从 $x_T \sim \mathcal{N}(0, I)$ 出发，每一步：

$$
x_{t-1} = \mu_\theta(x_t, t) + \sigma_t\, z, \quad z \sim \mathcal{N}(0, I)
$$

代码实现了两种方差选择：
- **simple_var=True**：$\sigma_t^2 = \beta_t$（固定方差）
- **simple_var=False**：$\sigma_t^2 = \frac{1 - \bar\alpha_{t-1}}{1 - \bar\alpha_t}\,\beta_t$（后验方差）

## 3. 模型架构

本项目提供两种去噪网络：

```
输入: 噪声图像 x_t (1, 28, 28) + 时间步 t
      │
      ▼
 ┌──────────────────────────────────────────┐
 │              ConvNet                      │
 │  Conv+BN+ReLU × N → 时间嵌入注入 → 输出   │
 │  轻量级，适合 MNIST 快速实验               │
 └──────────────────────────────────────────┘

 ┌──────────────────────────────────────────┐
 │              UNet                         │
 │  编码器: 逐步下采样 + 时间嵌入 + skip连接   │
 │  中间层: 双层残差块                        │
 │  解码器: 逐步上采样 + skip拼接 + 时间嵌入   │
 │  更强表达力，适合复杂图像                   │
 └──────────────────────────────────────────┘
      │
      ▼
输出: 预测噪声 ε (1, 28, 28)
```

**时间步嵌入**：使用正弦位置编码将整数时间步 $t$ 映射为向量，注入每一层卷积，让网络知道当前去噪到第几步。

## 4. 代码解析

### 4.1 前向扩散系数预计算

```python title="dldemos/ddpm/ddpm.py" showLineNumbers
class DDPM():

    def __init__(self, device, n_steps, min_beta=0.0001, max_beta=0.02):
        # highlight-start
        # 线性噪声调度：β 从 min_beta 线性增长到 max_beta
        betas = torch.linspace(min_beta, max_beta, n_steps).to(device)
        alphas = 1 - betas
        # highlight-end
        # key-start
        # 累积乘积 ᾱ_t = α_1 × α_2 × ... × α_t
        alpha_bars = torch.empty_like(alphas)
        product = 1
        for i, alpha in enumerate(alphas):
            product *= alpha
            alpha_bars[i] = product
        # key-end
        self.betas = betas
        self.alphas = alphas
        self.alpha_bars = alpha_bars
        # 预计算 clip_x0 模式的两个系数
        alpha_prev = torch.empty_like(alpha_bars)
        alpha_prev[1:] = alpha_bars[0:n_steps - 1]
        alpha_prev[0] = 1
        self.coef1 = torch.sqrt(alphas) * (1 - alpha_prev) / (1 - alpha_bars)
        self.coef2 = torch.sqrt(alpha_prev) * self.betas / (1 - alpha_bars)
```

### 4.3 逆向单步去噪

```python title="dldemos/ddpm/ddpm.py" showLineNumbers
    def sample_backward_step(self, x_t, t, net, simple_var=True, clip_x0=True):
        n = x_t.shape[0]
        t_tensor = torch.tensor([t] * n,
                                dtype=torch.long).to(x_t.device).unsqueeze(1)
        # 网络预测噪声 ε_θ
        eps = net(x_t, t_tensor)

        # 方差选择
        if t == 0:
            noise = 0
        else:
            if simple_var:
                var = self.betas[t]
            else:
                var = (1 - self.alpha_bars[t - 1]) / (
                    1 - self.alpha_bars[t]) * self.betas[t]
            noise = torch.randn_like(x_t) * torch.sqrt(var)

        # key-start
        # clip_x0 模式：先估计 x_0，裁剪到 [-1,1]，再计算均值
        # 这种方式比直接用 ε 估计均值更稳定
        if clip_x0:
            x_0 = (x_t - torch.sqrt(1 - self.alpha_bars[t]) *
                   eps) / torch.sqrt(self.alpha_bars[t])
            x_0 = torch.clip(x_0, -1, 1)
            mean = self.coef1[t] * x_t + self.coef2[t] * x_0
        # key-end
        else:
            mean = (x_t -
                    (1 - self.alphas[t]) / torch.sqrt(1 - self.alpha_bars[t]) *
                    eps) / torch.sqrt(self.alphas[t])
        x_t = mean + noise
        return x_t
```

### 4.4 UNet 时间步嵌入

```python title="dldemos/ddpm/network.py" showLineNumbers
class PositionalEncoding(nn.Module):

    def __init__(self, max_seq_len, d_model):
        super().__init__()
        assert d_model % 2 == 0
        pe = torch.zeros(max_seq_len, d_model)
        i_seq = torch.linspace(0, max_seq_len - 1, max_seq_len)
        j_seq = torch.linspace(0, d_model - 2, d_model // 2)
        pos, two_i = torch.meshgrid(i_seq, j_seq)
        # key-start
        # 正弦位置编码：让网络区分不同时间步
        pe_2i   = torch.sin(pos / 10000**(two_i / d_model))
        pe_2i_1 = torch.cos(pos / 10000**(two_i / d_model))
        pe = torch.stack((pe_2i, pe_2i_1), 2).reshape(max_seq_len, d_model)
        # key-end
        self.embedding = nn.Embedding(max_seq_len, d_model)
        self.embedding.weight.data = pe
        self.embedding.requires_grad_(False)
```
