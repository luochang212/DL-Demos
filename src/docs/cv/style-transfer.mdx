# Style Transfer — 优化一张图像

神经风格迁移不训练新的生成网络，而是冻结预训练 VGG，直接把输出图像像素作为待优化参数。

## 1. 内容与风格

内容损失比较输出图像与内容图像的高层特征：

$$L_{content}=\|F_l(x)-F_l(c)\|_2^2$$

风格使用 Gram Matrix 描述通道之间的相关性：

$$G(F)=FF^T,\qquad L_{style}=\sum_l\|G(F_l(x))-G(F_l(s))\|_2^2$$

总损失是两者的加权和。VGG 参数被冻结，梯度只更新输入图像。

## 2. 代码解析

```python
features = x.reshape(n * c, h * w)
gram_matrix = torch.mm(features, features.T) / (n * c * h * w)
```

Gram Matrix 抛弃特征出现的具体位置，只保留通道共同出现的统计关系，因此适合表达纹理和笔触。

优化阶段使用 LBFGS。每次 closure 先把图像裁剪到合法像素范围，再计算内容损失与风格损失，梯度只回传到 `input_img`。

## 3. 可调用入口

`run_style_transfer(content_path, style_path, output_path, num_steps, device)` 是无导入副作用的公共入口。导入模块不会下载权重或开始训练。

```bash
uv run python dldemos/StyleTransfer/style_transfer.py \
  --content dldemos/StyleTransfer/dancing.jpg \
  --style dldemos/StyleTransfer/picasso.jpg \
  --output work_dirs/style-transfer.jpg \
  --steps 300
```

首次运行会下载 torchvision 的 VGG19 默认权重。该方法优化速度慢，适合理解特征损失，不适合实时风格迁移。
