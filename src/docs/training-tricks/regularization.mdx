## 1. 什么是过拟合

当网络容量（参数数量）远大于训练数据量时，网络可以「记住」每个训练样本，包括噪声。此时：

- **训练集表现好**：Loss 很低，准确率很高
- **测试集表现差**：泛化能力弱，新数据预测不准

二维点分类实验中，过拟合表现为**决策边界过度扭曲**，试图精确包围每个点，而不是学到一个平滑的分类面。

正则化的目标：**约束模型复杂度**，让模型学到更简单、更平滑的决策边界。

## 2. 数学原理

### 2.1 Weight Decay（L2 正则化）

在标准损失函数后添加权重惩罚项：

$$
L_{\text{reg}} = L_{\text{original}} + \frac{\lambda}{2m} \sum_{l} \|W^{[l]}\|_F^2
$$

其中 $\lambda$ 是正则化强度，$m$ 是样本数，$\|W\|_F^2$ 是 Frobenius 范数的平方（即所有权重平方和）。

对 $W^{[l]}$ 的梯度变为：

$$
\frac{\partial L_{\text{reg}}}{\partial W^{[l]}} = \frac{\partial L_{\text{original}}}{\partial W^{[l]}} + \frac{\lambda}{m} W^{[l]}
$$

梯度更新时：

$$
W^{[l]} \leftarrow W^{[l]} - \eta \left(\frac{\partial L_{\text{original}}}{\partial W^{[l]}} + \frac{\lambda}{m} W^{[l]}\right) = \left(1 - \frac{\eta\lambda}{m}\right) W^{[l]} - \eta \frac{\partial L_{\text{original}}}{\partial W^{[l]}}
$$

**直观理解**：每次更新时，权重都会被**稍微缩小**（乘以 $1 - \frac{\eta\lambda}{m}$），防止权重增长过大。这也是「Weight Decay」（权重衰减）名称的由来。

注意：**偏置 $b$ 通常不参与正则化**，因为每一层只有一个偏置，参数量远少于权重，正则化偏置的意义不大。

### 2.2 Dropout

Dropout 在训练时以概率 $p$ 随机将某些神经元的输出**置零**：

$$
\tilde{a}^{[l]}_j = \begin{cases} 0 & \text{以概率 } p \\ \frac{a^{[l]}_j}{1-p} & \text{以概率 } 1-p \end{cases}
$$

除以 $1-p$ 是 **Inverted Dropout** 的关键——保证该层输出的**期望值不变**，这样测试时不需要调整。

**为什么 Dropout 有效**：

1. **打破共适应**：每个神经元不能依赖特定的其他神经元，被迫学到更鲁棒的特征
2. **隐式模型平均**：每次训练相当于采样一个子网络，最终模型等效于指数级数量子网络的平均
3. **类似 L2 正则的效果**：鼓励权重分布更均匀，避免单个权重过大

## 3. 代码解析

与上一章初始化教程共享 `BaseRegressionModel` 基类，网络结构更宽（`[2, 80, 50, 30, 1]`）以突出过拟合问题。重点看正则化相关的改动。

### 3.1 网络初始化：添加正则化选项

```python title="dldemos/Regularization/main.py" showLineNumbers
class DeepNetwork(BaseRegressionModel):

    def __init__(self,
                 neuron_cnt: List[int],
                 activation_func: List[str],
                 regularization: str = 'none'):
        # ...
        # highlight-start
        if regularization == 'weight decay':
            self.weight_decay = True
        else:
            self.weight_decay = False

        if regularization == 'dropout':
            self.dropout = True
        else:
            self.dropout = False
        # highlight-end
```

### 3.2 前向传播：Dropout 实现

```python title="dldemos/Regularization/main.py" showLineNumbers
    def forward(self, X, train_mode=True):
        A = X
        self.A_cache[0] = A
        for i in range(self.num_layer):
            Z = np.dot(self.W[i], A) + self.b[i]
            if i == self.num_layer - 1:
                A = sigmoid(Z)
            else:
                A = get_activation_func(self.activation_func[i])(Z)
            # key-start
            # Inverted Dropout：仅在训练时、隐藏层生效
            if train_mode and self.dropout and i < self.num_layer - 1:
                keep_prob = 0.5
                d = np.random.rand(*A.shape) < keep_prob  # 随机 mask
                A = A * d / keep_prob                       # 缩放保持期望不变
            # key-end
            if train_mode:
                self.Z_cache[i] = Z
                self.A_cache[i + 1] = A
        return A
```

两个关键细节：
1. **`train_mode` 检查**：测试时不做 Dropout，直接使用全部神经元
2. **`/ keep_prob` 缩放**：保证该层输出的期望值在训练和测试时一致

### 3.3 梯度更新：Weight Decay 实现

```python title="dldemos/Regularization/main.py" showLineNumbers
    def gradient_descent(self, learning_rate):
        for i in range(self.num_layer):
            # key-start
            if self.weight_decay:
                LAMBDA = 4
                # Weight Decay：W 乘以衰减因子 (1 - lr*λ/m)
                self.W[i] = (1 - learning_rate * LAMBDA / self.m
                             ) * self.W[i] - learning_rate * self.dW_cache[i]
                self.b[i] -= learning_rate * self.db_cache[i]  # b 不正则化
            else:
                self.W[i] -= learning_rate * self.dW_cache[i]
                self.b[i] -= learning_rate * self.db_cache[i]
            # key-end
```

### 3.4 损失函数：Weight Decay 的惩罚项

```python title="dldemos/Regularization/main.py" showLineNumbers
    def loss(self, Y: np.ndarray, Y_hat: np.ndarray) -> np.ndarray:
        # key-start
        if self.weight_decay:
            LAMBDA = 4
            tot = np.mean(-(Y * np.log(Y_hat) + (1 - Y) * np.log(1 - Y_hat)))
            for i in range(self.num_layer):
                tot += np.sum(self.W[i] * self.W[i]) * LAMBDA / 2 / self.m
            return tot
        # key-end
        else:
            return np.mean(-(Y * np.log(Y_hat) + (1 - Y) * np.log(1 - Y_hat)))
```

## 4. 实验结果

同样的宽网络（`[2, 80, 50, 30, 1]`，ReLU），训练 15000 步：

| 正则化方式 | 决策边界 | 特点 |
|-----------|---------|------|
| **无正则化** | 边界扭曲，出现不规则凸起 | 过拟合训练数据 |
| **Weight Decay（λ=4）** | 边界更平滑 | 权重被约束，不能太复杂 |
| **Dropout（p=0.5）** | 边界最平滑 | 神经元不依赖彼此，泛化最好 |
