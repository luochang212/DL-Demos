# 数据目录

本目录用于存放本地数据集。真实数据文件通常很大，或者受原始数据集许可限制，不能提交到 Git。模型运行常常依赖三类外部资源：训练数据、checkpoint、预训练模型；本仓库只提交说明和代码，不提交大文件。

## Git 规则

- `data/README.md` 可以提交，用来说明数据来源和目录约定。
- `data/` 下的真实数据文件默认被 `.gitignore` 忽略。
- 不要提交完整数据集、下载压缩包、解压后的图片批量文件、缓存、中间产物、checkpoint 或预训练权重。

## 文件放置约定

- 训练数据放在 `data/<dataset>/...`。
- 本项目训练产生的 checkpoint 和输出放在 `work_dirs/<chapter>/...`。
- 第三方预训练模型不要提交到 Git。若章节需要预训练模型，必须在章节 README 和网页教程里说明来源、下载方式、期望路径、文件大小或磁盘风险。
- 如果磁盘空间不足，优先使用章节提供的 `smoke` 命令或小数据集路径，不要下载大模型。

## 章节数据约定

每个需要真实数据集的章节，必须在章节 README 或网页教程里说明：

- 数据集名称和来源链接。
- 本项目期望的本地目录结构。
- 文件格式和最小样例。
- 是否有许可、用途或下载限制。
- 是否需要 checkpoint 或预训练模型；如果需要，说明来源和本地路径。
- 是否提供无需真实数据的 smoke 命令。

当前章节数据：

```text
data/celebA/img_align_celeba/
```

- DDPM 使用 MNIST 手写数字图片，默认路径为：

```text
data/mnist/
```

详见对应章节 README。
